# Student Marks Calculator

A simple Python project to calculate a student's total marks, average, percentage, grade, and result.

## Features
- Accepts student name and marks in five subjects.
- Calculates total marks, average, and percentage.
- Displays grade and pass/fail result.

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python marks_calculator.py
```
